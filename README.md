# Vlog 一键粗剪 + 自动成片工具（MVP）

上传视频素材后，网页会自动生成粗剪时间线，并通过 **ffmpeg.wasm** 在浏览器端执行裁剪与合并，直接输出 MP4 成片预览和下载。

## 功能

- 一次上传多个视频素材
- 自动读取每段视频时长
- 可选择 Vlog 风格（日常/旅行/美食）
- 自动生成粗剪时间线（保留文字结果）
- 一键自动裁剪与合并
- 成片预览（video 标签播放）
- 下载成品视频（MP4）
- 显示处理进度：正在读取视频 / 正在裁剪 / 正在合并 / 生成完成

## 运行

直接打开 `index.html` 即可（需联网加载 ffmpeg.wasm CDN）。

或本地静态服务：

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080`。

## 注意

- 首次点击“自动生成视频成品”时需要加载 ffmpeg 核心文件，可能较慢。
- 浏览器端处理高清视频会占用较多内存，建议先用 1080p 以内素材。
