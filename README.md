# Vlog 一键粗剪工具（MVP）

这是一个本地静态网页工具：你上传视频素材后，网页会自动读取时长并生成**Vlog 粗剪时间线**，可直接用于剪映/PR/CapCut 的二次精剪。

## 功能

- 支持一次上传多个视频素材
- 自动读取每段视频时长
- 可选择 Vlog 风格（日常/旅行/美食）
- 可设置目标成片时长、单镜头最长时长、转场时长
- 自动生成粗剪方案（每条素材的截取起止时间）
- 支持导出 JSON 剪辑计划
- 支持复制“给 AI/剪辑软件”的指令文本

## 运行

直接打开 `index.html` 即可。

或本地启动静态服务：

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080`。

## 注意

- 当前版本是“粗剪助手”，不会直接导出最终 MP4。
- 你可以把生成计划导入工作流，用剪映/PR 或自动化脚本进一步渲染成片。
